The first exercise is to clone this project to your local R Studio so that you can edit and run the code locally. Follow the steps below:

1. Click on the <span style="background-color:#238636; color:white; padding: 5px; border-radius: 5px">Code</span> button and copy-paste the **HTTPS** url to your clipboard.

2. Use the repo url to create a new project in RStudio (see guided instructions if you have never done this before)


## Guided instructions to clone a repo from GitHub to RStudio

### 1. In RStudio, create a new project by clicking in the top-right hand corner and selecting **New Project...**

![](images/git-exercise-new-project.png)

### 2. Select **Version Control** then **Git**. 

![](images/git-exercise-version-control.png)

![](images/git-exercise-git.png)


### 3. Paste your repo url in the **Repository URL** field.

![](images/git-exercise-paste-url.png)


* The **Project directory name** will be the name of the folder on your laptop so choose something sensible, e.g. **r4hds-exercise**.

* Finally, select the field **Create project as subdirectory of**. This is where the cloned repo folder will be stored on your laptop. If you move the folder later it will break the link with GitHub, that can be fixed but it is easier to just choose somewhere sensible now. 


### 4. Open the `.Rmd` file in RStudio and continue the exercise from there!
